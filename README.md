# Таймкоды ключевых мыслей из видео

Whisper поднимается локально в контейнере, на выходе — `out/<имя видео>.xlsx`:

- лист **Ключевые мысли** — таймкод, длительность блока, ключевая фраза, полный текст блока;
- лист **Транскрипт** — все сегменты распознавания с таймкодами.

## Запуск

Видео кладём в `source/` — берётся первый файл по алфавиту.

```bash
cp .env.example .env
make run        # CPU
make gpu        # GPU (nvidia-container-toolkit)
```

Прогон идёт детачем, `make logs` только показывает лог — Ctrl+C по логам распознавание
не обрывает. Остановить принудительно: `make stop`.

Без `make`:

```bash
docker compose up -d && docker compose logs -f
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d
docker compose run --rm timecodes python3 main.py source/другое_видео.mp4
```

## Настройка

Всё в `.env`:

| Переменная | Смысл |
|---|---|
| `WHISPER_MODEL` | `tiny…large-v3`, `large-v3-turbo` |
| `WHISPER_DEVICE` / `WHISPER_COMPUTE_TYPE` | `cpu`+`int8` или `cuda`+`int8_float16` |
| `WHISPER_LANGUAGE` | пусто = автоопределение |
| `BLOCK_SEC`, `MIN_BLOCK_SEC`, `PAUSE_SEC` | нарезка на смысловые блоки |

Меньше `BLOCK_SEC` — больше строк в Excel и более дробные мысли.

## Выбор модели под 4 ГБ VRAM (GTX 1650)

Проверено на этой машине:

- `large-v3` в 4 ГБ **не влезает** — видеопамять делится с браузером и рабочим столом,
  прилетает `CUDA failed with error out of memory` уже в середине прохода. Скрипт при этом
  сам откатывается на CPU, но там скорость 0.3–0.7x, то есть ~2–3 часа на час видео.
- `large-v3-turbo` — ~15x, влезает, но отдаёт текст **без пунктуации и заглавных**:
  ключевые мысли из него читаются заметно хуже.
- `medium` — ~6–8x, влезает, пунктуация на месте. Рабочий вариант по умолчанию.

## Кэш

- `work/*.wav` — извлечённая дорожка, повторный прогон не перекодирует видео.
- `work/*.<модель>.segments.json` — транскрипт. Пока он есть, смена `BLOCK_SEC` или
  правка формулировок пересобирают Excel за секунды, без распознавания.
  Перераспознать заново: `FORCE_ASR=1`.
- `make clean` удаляет wav; транскрипты остаются.

## Как выделяются «ключевые мысли»

Поток сегментов режется по паузам (не короче `MIN_BLOCK_SEC`, не длиннее `BLOCK_SEC`),
внутри блока берётся фраза с максимальным TF-IDF на слово — то есть самая
информативная относительно остального видео. Всё локально, без внешних API.
Это цитаты из видео, а не пересказ: на живой речи с «вот здесь», «ну-ка посмотрим»
часть строк выходит обрывочной — экстрактивный метод не умеет переформулировать.
Если нужен именно пересказ мысли, поверх листа «Транскрипт» (или `work/*.segments.json`)
надо пустить LLM — это отдельный шаг и он уже не локальный.

# Тайм-коды эфира

Telegram-бот: присылаешь запись эфира (видео или аудио до 2 ГБ) — получаешь `.txt` с
промптом для кликбейтных тайм-кодов YouTube и расшифровкой. Файл целиком отправляется в
любую нейросеть.

1. Файл встаёт в очередь. В работе всегда один эфир, остальным бот пишет, сколько
   эфиров перед ними и примерно через сколько ждать результат.
2. ffmpeg достаёт звук, Whisper `small` распознаёт речь на CPU, сегменты собираются в
   блоки по ~90 секунд с таймкодами.
3. В начале файла — промпт, длина эфира и диапазон числа тайм-кодов, дальше расшифровка.
   Метки блоков в ней уже в формате глав YouTube.

Видео, звук и результаты не хранятся: всё удаляется сразу после ответа. Очередь живёт в
памяти, при рестарте недоделанные эфиры теряются — их надо прислать заново.

Бот отвечает только пользователям из `ACCESS_IDS`, остальных молча игнорирует.

## Устройство

| Сервис | Зачем |
|---|---|
| `bot-api` | Локальный [telegram-bot-api](https://github.com/tdlib/telegram-bot-api): облачный отдаёт боту файлы только до 20 МБ |
| `bot` | aiogram на поллинге, очередь, пайплайн |

Распознавание идёт в отдельном процессе с `nice 10`, процесс живёт одну задачу — модель не
висит в памяти между эфирами. Звук читается с диска через `memmap` кусками по 10 минут,
поэтому память не растёт с длиной эфира.

## Нагрузка на сервер

Сервер общий с другими проектами (2 vCPU, 3.8 ГБ RAM), поэтому контейнер `bot` ограничен
`cpus: 1.5` и `mem_limit: 2g`. Замер на нём: 10 минут эфира за ~190 с (3.16x), пик памяти
1.3 ГБ — эфир 2.5 часа обрабатывается ~50 минут. Скорость в оценке ожидания — `asr.SPEED`.

## Запуск

```bash
cp .env.example .env   # заполнить
make up                # сборка, запуск, лог бота
make test
```

Перед первым запуском на локальном `bot-api` бота нужно один раз разлогинить из облачного
API, иначе Telegram не гарантирует доставку апдейтов:

```bash
curl https://api.telegram.org/bot$BOT_TOKEN/logOut
```

## Переменные `.env`

| Переменная | Смысл |
|---|---|
| `BOT_TOKEN` | токен бота |
| `ACCESS_IDS` | ID пользователей Telegram через запятую |
| `TG_API_ID`, `TG_API_HASH` | с my.telegram.org, для `bot-api` |
